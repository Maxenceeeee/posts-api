# Posts API

Projet Node.js initialisé avec Koa, `@koa/router` et `koa-bodyparser`.

## Démarrer

```sh
npm install
npm start
```

Le serveur écoute sur le port `3000` par défaut. Pour le changer, définir la
variable d'environnement `PORT`.

Le serveur et ses dépendances sont en place ; les routes et la gestion des posts
restent à implémenter.
